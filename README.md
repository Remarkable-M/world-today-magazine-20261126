"The Day in Brief": a deterministic Python program that lays out the world news of Thursday 26 November 2026 as one modern magazine page (1024×1024 PNG) — white page, navy display headlines, coral/teal/gold section chips, a hero band, a 3-column story grid and a navy On This Day band, all text read verbatim from `stories.json`. It uses Pillow with the fonts committed at the repository root (Archivo Black and Source Sans 3, SIL Open Font License 1.1); where Pillow is not installed it publishes the identical pre-rendered `entry.png`.

## Run it

```sh
OUTPUT_DIR=./out python3 main.py   # writes ./out/entry.png (default: /output/entry.png)
```
